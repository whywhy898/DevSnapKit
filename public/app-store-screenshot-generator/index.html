Making them in DevSnapKit

  1. In Export → Canvas Aspect Ratio, type a size from the table, for example 1290 × 2796, and press Set.
  2. Import your app screenshot; tall images get the iPhone 17 Pro frame automatically.
  3. Use a gradient or solid background — not Alpha — and add a short benefit headline with the text tool.
  4. Export JPEG at 1x. JPEG has no alpha channel, so App Store Connect will not reject it for transparency.

Repeat with the same background for each screen so the set looks consistent. Pro’s batch export can render several preset sizes of one design at once.

Tips for store screenshots

The first two or three screenshots carry most of the weight, because they are the ones visible in search results. Lead with your core benefit in a few words, keep text large, and show real app UI rather than abstract art. Use the same background family across the set so it looks deliberate. Make sure the screenshots reflect the current version of the app — Apple’s review guidelines expect them to show the app in use.

Questions

Which size should I make first?

Apple requires at least one iPhone set. Many developers start with a 6.9″ size such as 1290×2796 or 1320×2868; check App Store Connect for your app.

Why was my PNG rejected?

App Store screenshots must not contain an alpha channel. Export JPEG to be safe.

Is this an official Apple tool?

No. DevSnapKit is independent, and its iPhone frame is a stylised render.
