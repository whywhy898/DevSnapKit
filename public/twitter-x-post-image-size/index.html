Making the image

The button above opens the studio on the Twitter/OG canvas (1200×630), which is also the shape X uses for link previews. For a bigger in-feed image, switch to 16:9 or 1:1 under Export → Canvas Aspect Ratio. Then frame the screenshot, pick a background with strong contrast against X’s dark and light themes, and keep any headline short so it is readable on a phone.

Export WebP or JPEG to stay well under 5MB, or PNG for crisp UI text. If the post links to your site, set a matching card with the OG image generator.

Make screenshots readable on X

Most people see your image on a phone, at a few hundred pixels wide. Crop to the part of the UI that matters, add padding so the edges are not cut on any client, and increase contrast between the screenshot and the background. If you post several images, X arranges them in a grid that crops each one, so keep the important content in the middle of each image.

Questions

What is the best size for a screenshot on X?

16:9 (1920×1080) suits wide UI screenshots; 1:1 suits mobile or square crops. Both display well as single images.

What size is the X link preview image?

A 1200×630 image is the common choice for summary_large_image cards. It is the Twitter/OG preset in DevSnapKit.

Does X compress images?

Yes, X may recompress uploads. Starting from a clean export at 2x helps text stay legible.
