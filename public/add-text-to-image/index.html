FOLLOW ALONG IN THE STUDIO

How to write on a screenshot

Open the text studio, replace the sample image with your screenshot, and use Add text to create a caption. Style and move the text, then download the finished image. Here is the complete process in the actual editor.

  1. STEP 01 · YOUR SCREENSHOT

    Replace the sample with your image.

    Open the text studio. In the bar below the canvas, choose Replace Image and select a screenshot from your computer. You will see it in the canvas, ready for a headline or label.

    For this walkthrough, we used the same public MDN CSS documentation capture shown in the comparison above. The image is processed in your browser.

  2. STEP 02 · YOUR WORDS

    Add a caption. Give it room.

    Choose Add text in the toolbar above the canvas and type your words. Our example uses “Understand CSS grid.” Select Elements → Text in the inspector to finish typing and open the style controls.

    Choose the font, size, weight, alignment, and colour. Use the Move handle to place the caption; drag a side handle to change the box width and line breaks. Scroll down in the panel for precise position controls.

    Here, a 38 px Manrope headline sits in the space above the screenshot. Keep labels beside the detail they explain, so the original UI stays readable.

  3. STEP 03 · THE FINISHED IMAGE

    Check the whole canvas, then export.

    Open the Export tab in the inspector. Choose PNG, WebP, or JPEG, check the displayed pixel dimensions, and select Download for the chosen scale. This example was downloaded as a PNG.

    If a text box extends outside the canvas, export asks you to fix it. Move the box inward, widen it to reduce wrapping, or shorten the caption before trying again.

    The downloaded image contains the screenshot and caption together. Text stays editable in your open studio session, but the exported file has no editable text layers.

Add context without covering the evidence.

Use a short headline to introduce the screenshot, or a label beside one important detail. Leave menu labels, numbers, and controls visible. For a framed composition, style the screenshot and background; for a shared-link preview, use the Open Graph image layout.

WORDS THAT STAY EDITABLE

Control the type, then the image.

Two bundled typefaces.

Manrope offers normal weights 400, 600, 700, and 800. Gelasio offers weights 400, 600, and 700 in normal and italic styles. Custom font uploads are not supported.

Alignment that behaves.

Choose left, centre, or right alignment. Adjust the box width to control where the lines break.

Overlapping boxes are findable.

Each text box has an entry in the text picker, so you can select one even when another box overlaps it.

Undo covers text and images.

Adding, moving, restyling, and deleting text use the same undo history as your image edits.

Before you add the words.

Can I edit the text after adding it?

Yes. First use Add text to create a text box. Then click that text on the canvas, or select its entry in Elements → Text and choose Edit on canvas. It remains editable in your open studio session, including after you download an image.

Does the text become part of the image?

Only in the exported file. Inside the current studio session it remains an editable object. The exported PNG, WebP, or JPEG contains the finished visual, not editable text layers.

Can I change words already inside my screenshot?

No. DevSnapKit adds new text boxes over the image or in the surrounding canvas. It does not recognise, erase, or replace text baked into the screenshot. To correct the original UI wording, change it in the source app and take a new screenshot.

Can I rotate a text box?

No. You can move a text box, resize its width, and restyle it, but text rotation is not supported.

What happens if the text is too long for the canvas?

Export is blocked with a message naming the box. Shorten the text, reduce its size, or adjust the width so the entire box fits before exporting.

Is adding text to images free?

Yes. Text, logo uploads and QR codes are included in Free. Pro adds premium templates, high-resolution export presets, batch export for multiple canvas sizes, and premium gradient backgrounds. The final pixel dimensions are shown before export.
