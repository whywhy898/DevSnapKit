Before you build the gallery.

What image sizes does Product Hunt need?

Check Product Hunt's current launch documentation, then choose a matching canvas size in DevSnapKit. The 1600×1200 image on this page is our demonstration export, not a guarantee of the platform's current specification.

Is there a template that looks like Product Hunt?

There is no Product Hunt template. The studio provides a canvas, frames, backgrounds, and text; you compose the image.

Can I make several images from the same layout?

You can change the screenshot and text to compose each gallery image. Pro batch export produces different sizes of the same composition; it does not automatically generate different gallery slides. Review the size variants and adjust layouts as needed.

Do I need to write the copy elsewhere?

No. Use Add text to create a text box, then edit it directly on the canvas. You can also prepare your headlines elsewhere and paste them into the text box.

Can I keep my brand consistent across the set?

Reuse the same background and frame choices while composing each image. Logo placement is included in Free; you choose the position, scale, and opacity.

Is batch export free?

Pro includes premium templates, high-resolution export presets, batch export and premium gradient backgrounds. Single exports are available in Free. The final pixel dimensions are shown before export.
