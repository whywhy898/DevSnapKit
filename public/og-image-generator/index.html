A few things worth knowing.

What size should an OG image be?

DevSnapKit includes a 1200×630 preset labelled Twitter / OG. Use the destination platform's current documentation to decide whether that size fits your link preview; requirements and cropping can vary.

Does DevSnapKit capture my website automatically?

No. You take the screenshot yourself and import it. DevSnapKit composes and exports the image.

Can I add my own headline?

Yes. Use Add text to create a text box, then edit it directly on the canvas. The text controls include font, size, weight, italic where supported, colour, and alignment.

What happens if a text box falls outside the image?

Text boxes are constrained to the canvas. If a box still overflows, export is blocked with a message identifying it. Shorten the words, reduce the size, or adjust the box width before exporting.

Can I use my logo?

Yes. Logo uploads are included in Free, with position, scale, and opacity controls.

Is it free?

Text, logo uploads and QR codes are included in Free. Pro adds premium templates, high-resolution export presets, batch export for multiple canvas sizes, and premium gradient backgrounds. The final pixel dimensions are shown before export.
